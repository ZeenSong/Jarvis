# M3.3 实施与验收记录

状态：进行中，不能按完整验收通过交付。以 `M3.3.md` 的全部要求为范围。

## 已落地及证据

- `JarvisConversation` 替换 PoC，沿用 assistant-ui 的运行时、输入框和滚动；移除独立 Inspector 与 500ms 轮询。
- 回复适配器订阅 Gateway EventTarget，发送前订阅，文本按 revision 去重；重连读取持久化状态，不重发已接受的任务。
- `conversation_events` 保存 Reasoning、工具、Processing、Render 的首次序号与更新版本，刷新后恢复顺序。
- Execution Stream 按参考图改为有序横向阶段卡片：显示阶段序号/类别/状态，宽屏排布、窄屏可横向浏览；终态事件有可计算时间戳时显示总耗时。MCP 命名空间中的 HA、Frigate、Immich 调用被投影为普通用户文案，不显示 `mcp__...` 协议名。
- 当前固定 Hermes 镜像原先只把 `reasoning.available`（最多 500 字）送进 Run SSE。新增可重复镜像补丁，把 Hermes 的原生 `reasoning_callback` 连接到 `reasoning.delta` SSE，并移除完成段落的 500 字截断；Jarvis 收到 `reasoning.available` 时会把全文校正到同一段已有事件，避免把增量和最终段落重复展示。隔离 PostgreSQL 用例覆盖增量+完整段落合并、完整长文本和刷新恢复；补丁已在生产 Hermes 镜像部署，真实 Provider 是否实际返回增量仍待实机验证。
- 固定镜像的工具事件没有 call ID，按同名未完成调用队列关联，结束的调用不复用 ID；布尔 `error=true` 按失败处理。
- 完成事件的 output 校正丢失的文本尾部；非终态 run 事件不终止 SSE 消费；CRLF/分段 UTF-8 与消费结束释放 reader 有测试。
- Result Host 共用 UI Protocol V2；简单画廊内联、复杂结果侧栏、资源逐个到达更新、关闭恢复宽度。
- `conversation_results` 与 Workspace Artifact 关联；同一任务类型的后续 Turn 更新同一 Artifact。
- 普通模式隐藏 Hermes/系统一级入口和 Workspace 源码编辑；历史记录移入左侧导航，手机可打开历史菜单。
- 深蓝视觉、固定输入区域、阶段状态、Skeleton、照片预览及键盘关闭已做浏览器检查。
- Composer 推理强度已接通真实能力目录：服务端只在当前 Profile 的当前 Provider/Model 明确声明 reasoning 时显示快速/标准/深度；用户选择经消息持久化进入 Hermes `model_options.reasoning_effort`。目录缺失、请求失败或模型未声明时隐藏控件。
- Composer Stop 已调用 Hermes `/v1/runs/{id}/stop`；等待上游终态后才持久化为取消。排队中的任务可本地原子取消，运行任务仍由 Hermes 终态确认。
- 新对话不再把首句截断作为标题；首轮回答后由配置模型发起无工具的标题摘要请求，异步更新列表和当前页。只处理未命名新会话的首轮，失败不影响回答，手动标题不覆盖。
- 新 MCP 图片落入 PostgreSQL 的会话级 Media Resource（owner、来源、MIME、文件名、元数据和 30 天过期）；正文只输出 `MEDIA_RESOURCE:<UUID>`，Gallery 接受 `resource_id` 并由鉴权内容路由加载。旧路径仅保留给既有消息/视图。

## 上游协议事实（本地固定镜像源码检查）

- `/v1/capabilities`：`model_options=true`、`skills_api=true`、`run_stop=true`。
