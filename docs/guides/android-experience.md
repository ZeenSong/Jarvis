# Android 体验：与 Web 对等的私人云与语音通话

Android 客户端不是 Web 的只读投影。它复用同一套 Gateway 协议、持久任务、语义视图与账户体系，并针对触屏重新组织了导航、卡片和操作流。

## 功能对等

| Web 能力 | Android 实现 |
| --- | --- |
| 首页：状态、空间、应用、任务、对话、Hermes | 首页 LazyColumn：Lantern Hero、CPU/内存/存储、任务队列、空间封面、应用卡片、当前任务、最近对话、Hermes 入口 |
| 空间 | 六个空间卡片；照片/家庭直接打开 Immich / Home Assistant；开发跳到任务；其余展示真实边界说明 |
| 应用中心 | CasaOS 应用状态、连接状态、检测地址、可调用操作数；一键连接、只读凭据填写与验证、CasaOS 重新认证、让 Jarvis 分析 |
| 任务 | 待处理审批、搜索与状态筛选、任务分组、定时任务创建/启停/删除 |
| Jarvis 对话 | 流式回复、执行过程、Skills、推理强度、停止、提问、审批、内联动态结果、工作区、对话历史与删除 |

| 认证 | 登录、首次注册、管理员邀请；设备 ID 稳定保存在本机 |

## 语音通话（类似豆包）

入口：首页 Hero 麦克风、首页语音卡片、顶栏麦克风、Jarvis 页头、对话输入区、空会话欢迎页。

一次通话的状态机：

```text
准备 → 聆听 → 思考 → 流式回答 + 播报 → 聆听 → …
          ↑                    │
          └──── 轻触打断 ──────┘

无系统识别服务：
准备 → 云端识别（录音 → 上传 → 转写） → 思考 → 回答 + 播报 → 云端识别
```

- **全屏光球**：聆听时扩散圆环、思考时轨道弧线、播放时按音频电平呼吸；点按光球在聆听时结束这句话，在回答时打断。
- **流式识别**：`SpeechRecognizer` 返回 partial 结果时实时上屏；说完自动提交。
- **流式回答**：使用与文字对话相同的 `conversation.message` 通道；`conversation.message.delta` 驱动文字，`VoiceText` 把 Markdown 清洗成适合朗读的句子，按句送入 TTS。
- **持续对话**：TTS 队列播完后自动重新开始聆听；回答未完成时不会抢麦。
- **打断**：停止 TTS、取消当前 turn 的本地收集、向服务端发送 `conversation.stop`，立即重新聆听。
- **控制**：静音/取消静音、扬声器/听筒、键盘输入、结束通话、0.85×/1.0×/1.15× 语速；通话计时与实时电平。
- **无 GMS 设备兜底**：检测不到系统识别服务、语言包不支持或连续失败时，自动显示“云端识别 / 自建 Whisper”卡片。手机录 16 kHz 单声道 WAV（最长 30 秒），上传到自己的 Jarvis 服务端转写，再作为本轮输入发送；回复仍由手机 TTS 播报。
- **降级**：系统识别不可用且服务端未配置 Whisper 时显示键盘和输入法麦克风入口；没有 TTS 时只显示字幕并继续文字流；权限被拒绝时展示授权说明。
- **隐私**：有系统语音服务时，ASR/TTS 由设备/厂商引擎处理；使用自建 Whisper 时，音频只上传到自己的 Jarvis 服务器，不经过第三方 ASR。Jarvis 服务端不持久化音频，只保留转写文字。

### 语音依赖

- Android 8.0（API 26）及以上。
- 有系统语音服务时使用 `android.speech.RecognitionService` 和 TTS 引擎；中文识别与中文音色取决于系统/厂商服务。
- 华为 Mate X5、荣耀等无 GMS 设备通常没有系统识别服务；部署 [自建 Whisper](self-hosted-whisper.md) 后即可使用云端识别。
- 首次进入语音通话会请求 `RECORD_AUDIO`。静音只关闭麦克风，不结束通话；云端录音同样需要麦克风权限。
- 蓝牙耳机、车载等音频路由由系统决定；扬声器开关使用 `AudioManager` 的扬声器路由。

### 排障

| 现象 | 检查 |
| --- | --- |
| 一直“正在聆听”但没有文字 | 确认系统语音服务已安装、中文语言包可用；可点键盘改用文字输入，或部署自建 Whisper |
| 提示“语音识别不可用” | 华为/荣耀等无 GMS 设备属预期；部署 Whisper 后重新进入语音页，或使用输入法麦克风 |
| 云端识别提示“服务端还没有配置 Whisper” | 检查 Jarvis 的 `SPEECH_BASE_URL` 和 Whisper 容器，见 [自建 Whisper](self-hosted-whisper.md) |
| 能识别但听不到播报 | 检查媒体音量、TTS 引擎与中文音色；界面底部会显示“语音播报不可用” |
| 打断后没有重新聆听 | 检查麦克风权限是否被系统回收；重新进入通话 |
| 模拟器上无声/卡顿 | 使用带音频后端的模拟器（`-audio default`），不要使用 `-no-audio`；无 Google 语音服务的镜像可能无法识别 |

## 图片对话

1. 在对话输入区点“＋”选择 PNG/JPEG/WebP（单张≤2 MB）。
2. 发送后先上传到会话级媒体库，再携带 `MEDIA_RESOURCE:<id>` 进入对话。
3. 服务端先让多模态模型描述图片/转写图中文字，再把描述与用户问题一起交给任务流。
4. 图片在用户气泡中按原图渲染；回答里的图片仍使用同一媒体渲染器。

## 构建与验证

```bash
cd apps/android
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest   # 需要设备或模拟器
```

语音相关的纯逻辑（Markdown 清洗、句子切分、长文本切块）在 `VoiceTextTest`；外观调色板与状态文案在 `AppearanceTest`。
