# 家庭服务接入

Jarvis 可以通过加密的 Integration Credential Store 连接 Home Assistant、Immich 和摄像头服务。本文只描述通用安全流程，不记录任何家庭的真实地址、设备名称、账号或网络拓扑。

## 准备原则

- 为 Jarvis 创建专用服务身份，权限只覆盖需要读取或操作的资源。
- 优先使用可撤销、可轮换的 Token 或 API Key，不复用管理员密码。
- 服务地址使用 HTTPS、Tailnet 地址或仅服务器可访问的内部 DNS。
- 凭据只通过 Jarvis 设置页面或受保护的部署 Secret 写入，不粘贴到聊天、日志或 Issue。

## 配置流程

1. 在上游服务创建专用凭据。
2. 以管理员身份打开 Jarvis 的“设置与待处理”→“家庭服务连接”。
3. 选择服务，填写内部地址、凭据和便于识别的非敏感标签。
4. 保存后检查连接验证结果；界面不应回显秘密值。
5. 使用普通成员账户验证 Household 隔离和最小读取范围。

## 服务建议

| 服务 | 建议凭据 | 最低验收 |
| --- | --- | --- |
| Home Assistant | 专用长期访问 Token | 只能读取授权实体；写操作需要明确审批 |
| Immich | 专用 API Key | 只能访问预期用户/相册；媒体仍通过 Jarvis 鉴权路由展示 |
| 摄像头 / Frigate | 只读 viewer 或短期 Bearer Token | 只能查询事件和截图；不得暴露 RTSP 密码或局域网拓扑 |

## 撤销与轮换

先在 Jarvis 中撤销连接，再在上游服务吊销旧凭据。轮换后验证旧凭据立即失效、重启后新凭据仍可用，并检查日志中没有秘密值。涉及真实门锁、灯光或其他家庭设备的拒绝测试应在隔离资源上进行，不要通过真实破坏性操作验证权限。
