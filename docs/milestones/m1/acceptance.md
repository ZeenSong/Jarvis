# M1 验收

状态：**已由使用者验收通过（2026-09-08）**。Android 真机通过 Tailscale 连接部署的服务器，App 正确读取服务器运行状态。M1 以 v0.1.0 发布。

## 验证证据

- TypeScript 类型检查与构建通过。
- 单元测试覆盖 IPv6 选择、Agent 超时、Token 计价、统计范围、消息校验及 LLM 成功/错误/超时。
- PostgreSQL 集成测试覆盖一次性配对、HTTP/WS 鉴权、Agent 身份边界、生命周期、会话、用量去重、聚合、事件推送和重启持久化。
- Android 构建、JVM 测试及 lint 检查通过；模拟器 instrumentation 测试走通配对、系统状态、Agent 任务、用量和详情页面。
- 模拟器验证服务重启后的自动重连、网络切换后的在线状态及用户启用的前台连接服务。
- 容器已验证宿主机系统/GPU 指标采集；数据库停启时 readiness 正确变化，恢复后重新可用。
- 真实外部 LLM 调用通过统一 Wrapper，Token、请求数及当次预估费用自动入库。
- 使用者确认 Android 真机的 Tailnet 连通性和状态展示。

## 发布边界

未把所有长时间运行或故障注入场景标成自动化通过：真实公网 IPv6 地址变更、不同手机省电策略、断电恢复等仍适合持续观察。Android 后台运行受系统休眠及强制停止约束。费用为可配置的估算，缺失价格时显示未知。

公开记录只保留验证结论，不包含设备地址、账号凭据、本机路径、调用 UUID、日志或个人用量明细。
