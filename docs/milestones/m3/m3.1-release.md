# Jarvis M3.1 发布记录

> 历史里程碑记录，不是当前操作手册。命令、镜像标签和环境状态只代表当时版本；部署请以 [`docs/guides/deployment.md`](../../guides/deployment.md) 为准。

版本：`v0.3.1`

Android：`versionCode 4` / `versionName 0.3.1`

## 本次发布

- 同步 Hermes durable Run、任务生命周期、Workspace 持久化和工具状态到 Android。
- Android 对 `conversation.status`、`task.*`、`agent.run.*` 和 `workspace.*` 事件即时刷新。
- 修正 Web/M2 测试夹具，使其覆盖当前 `/v1/runs` durable Hermes 协议。
- 统一服务端、容器、Node 包和 Android 版本号为 `0.3.1`。

## 验证

- `npm run typecheck`
- `npm run typecheck:web`
- `npm run build:web`
- `npm test`
- `npm run test:web`
- `apps/android/gradlew assembleDebug testDebugUnitTest`

APK：`apps/android/app/build/outputs/apk/debug/app-debug.apk`。

## 已知边界

该版本的 APK 为 debug 签名；实体 Android/Tailnet 验收和 CasaOS 重新认证仍需在目标环境完成。
