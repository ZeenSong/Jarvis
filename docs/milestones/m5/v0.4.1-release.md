# Jarvis v0.4.1 — Android 全功能对齐与语音通话

版本：`v0.4.1`  
Android：`versionCode 6` / `versionName 0.4.1`  
基线：`v0.4.0`

## 本次发布

- Android 客户端完整覆盖 Web 的主要产品面：首页、空间、应用中心、任务与审批、定时任务、Jarvis 对话、执行过程、动态结果、工作区、Hermes、系统与 AI 用量、设置、用户/角色/能力管理、邀请、登录会话、通知与深链。
- 新增豆包式全屏语音通话：实时识别、流式回答、按句 TTS 播报、轻触打断、自动续听、静音、扬声器、键盘输入、语速与通话计时。
- 语音使用设备系统语音服务；Jarvis 服务端只接收转写文字与回复文本，不接收或保存通话音频。
- 视觉统一为 Lantern 设计语言，支持 `Lantern / Moss / Clay / Graphite` 四套外观和独立深/浅色模式。
- 修复 `gateway.subscribe` 主题数超过服务端 32 个上限导致回复卡在“正在回答”的问题，并增加回归测试。
- 增加 WebSocket 事件丢失时的 HTTP 回复对账，提升弱网与断线重连后的可靠性。
- 应用中心支持 CasaOS 状态、一键连接、只读凭据验证、重新认证，以及直接打开原应用。
- Hermes 控制台可在应用内通过认证 WebView 打开，复用当前 Jarvis 登录状态。

## 安装

下载 `jarvis-0.4.1-android-debug.apk`。该 APK 使用与 `v0.4.0` 相同的 Android Debug 签名，可从 `v0.4.0` 覆盖升级；如设备上仍提示签名不一致，请先卸载旧版再安装。Debug 签名适合自托管与侧载，不是 Google Play 生产签名。

## 验证

- Android：`assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest` 通过。
- Android 仪器测试：21 个自包含 UI 测试通过；3 个旧配对式 E2E 测试按设计跳过。
- 服务端：TypeScript 类型检查、Web 类型检查、Node 测试、构建与容器构建通过。
- API 35 模拟器实测：登录、首页、浅色主题、设置、任务、流式对话、语音通话（问候 → 发言 → 流式回答 → 自动续听）、Hermes WebView。

## 已知边界

- 语音识别与 TTS 依赖设备系统语音服务，中文音色与离线能力由系统/厂商决定。
- 当前没有唤醒词或后台常驻拾音；通话需要前台页面。
- 应用连接需要服务端先完成 CasaOS 配置；本次发布验证了未配置/错误状态和连接 API 路径。
- Debug APK 仅用于自托管体验与测试，不应作为商店正式包分发。
