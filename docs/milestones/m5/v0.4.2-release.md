# Jarvis v0.4.2 — 自建 Whisper 与无 GMS 云端语音识别

版本：`v0.4.2`  
Android：`versionCode 7` / `versionName 0.4.2`  
基线：`v0.4.1`

- 新增**自建 Whisper 语音识别**：华为 Mate X5、荣耀等没有 GMS/系统语音识别服务的设备，不再只能看到“语音识别不可用”。
- Android 语音页检测到系统识别不可用、中文语言包不支持或连续失败后，自动显示“云端识别 / 自建 Whisper”卡片。
- 手机录制 16 kHz 单声道 WAV（最长 30 秒），上传到自己的 Jarvis 服务端；服务端转发给私有 Docker 网络内的 Speaches（faster-whisper large-v3）。
- 音频不经过 OpenAI、讯飞等第三方 ASR；Whisper 端口不发布到主机，Android 只使用现有的 Jarvis 登录令牌。
- TTS 仍由手机系统语音引擎完成；云端转写结果作为当前语音会话的一轮发送，回答继续按句播报。
- 服务端新增需要登录的 `GET /api/v2/speech/status` 与 `POST /api/v2/speech/transcribe`，音频上限 8 MB，JSON 请求体上限 12 MB。
- 新增 `deploy/whisper/` 一键部署：CUDA/CPU 镜像、模型缓存、API Key、模型下载与预热、Jarvis 环境变量输出。
- Android 语音识别增加语言回退 `zh-CN → cmn-Hans-CN → zh → zh_CN`，并在系统识别彻底不可用时切换到云端模式，不再无限重试。
- Release 工作流增加 tag 与 `versionName` 一致性校验，避免 tag 与安装包版本错位。

## 部署

```bash
./deploy/whisper/install.sh
```

然后把脚本输出的 `SPEECH_*` 变量加入 Jarvis 服务端环境并重启 `jarvis-server`。完整说明见 `deploy/whisper/README.md` 与 `docs/guides/self-hosted-whisper.md`。

实测环境：AMD Ryzen 7 9700X + RTX 5070 12 GB；`large-v3` 常驻约 4 GB 显存，预热后 8 秒中文音频转写约 2.3 秒，冷启动约 20 秒。CPU 环境建议 `small`/`medium` + `int8`。

## 验证

- 服务端：`npm run typecheck`、`npm run typecheck:web`、`npm test`（含新增 speech 模块测试）通过。
- 端到端：手机 WAV 格式音频 → Jarvis `/api/v2/speech/transcribe` → Whisper 返回中文文本，实测 2.27 秒。
- Android：`compileDebugKotlin`、`testDebugUnitTest`、`lintDebug`、`assembleDebug`、`assembleDebugAndroidTest` 通过。
- 发布 APK 使用与 `v0.4.0`/`v0.4.1` 相同的 Debug 签名，可覆盖升级。

## 已知限制

- 华为等设备如果没有系统识别服务，必须部署 Whisper 后才能使用 App 内的云端识别；未配置时仍可使用键盘或输入法麦克风。
- 当前云端模式是“点开始录音 / 点停止并识别”，不是系统 ASR 的自动 VAD 连续拾音；通话回复播完后会回到云端识别待命状态。
- Debug APK 适合自托管与侧载，不是 Google Play 生产签名。
- 语音识别质量由模型、录音环境与麦克风决定；嘈杂环境建议使用 `large-v3` 并靠近手机说话。
