# Jarvis v0.4.4 — 语音/图片/DSH 能力与 CI 修正

版本：`v0.4.4`  
Android：`versionCode 9` / `versionName 0.4.4`  
基线：`v0.4.3`

这是 v0.4.3 的补丁版本，功能与 v0.4.3 相同：

- 自建 Whisper `large-v3-turbo`，热态 8 秒中文音频约 0.6 秒；Jarvis 接口实测 0.79 秒。
- Android 云端录音静音自动发送、TTS 打断和更短的问候。
- Web/Android 图片上传，服务端多模态理解图片和图中文字。
- DeepSeek Harness 作为默认 Coding Agent，按任务执行并回传工具步骤、用量与结果。

本次修正：

- M2 恢复测试不再把 `coding-agent` 的运行时写死为 `codex`；它读取当前数据库中的运行时并注册对应测试运行时。这样 DSH 成为默认 Coding Agent 后，CI 的归档 Worker 清理测试仍然成立。
- 版本号与 tag 同步到 `0.4.4`。

发布 APK 与 v0.4.3 使用相同的 Debug 签名，可直接覆盖安装。
